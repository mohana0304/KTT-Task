Browser Environment :

   * when js is runs in the browser it provide extra object 
     --> window,document,location,navigator,history 

   * window is a global object 
     --> inside window it has lots of methods and object (DOM,BOM,timer(Settimeout,setinterval),alert)
        And also it provide Web API or Browser API (setTimeout,fetch,localstorage,document)

   * document is HTML Page
     -->use to control the page , when the content is change page updates instantly
     -->document.body,document.title

   * location (url info) current page url
     -->location.href,location.reload()

   * navigator (browser info)
     -->navigator.userAgent - shows Broswer name,device info
     -->navigator.onLine - true/false (internet)
     -->navigator.language - en-US

   * history (page History)
     -->previously visited pages
     -->history.back() - go to previous page
     -->history.forward() - go forward
     -->history.length -no of pages in history


   * these allow js to -->talk to the DOM
                            make network requests
                            store data
                            Handle timers

Node properties:

In DOM everything is a node
     -->eg: <div>"hello"</div>
        <div>- element node
        "hello"-text node

    Node properties ---> nodeType
                         nodeName
                         nodeValue

   * nodeType is just a number that tells what kind of node it is
           --> 1= Element (HTML tag)
               3= Text (content inside tag)
               8= comment
            
   * nodeName tell which tag it is
          
   * nodeValue/textContent tell what is inside
        -->nodeValue -old way it return null beacuse element has no direct value
        -->textContent -crt way


Attribute -->original HTML value(Initial value)
             Does Not change automatically

property -->current value in JS
            changes when user types or js updates
            .value,.checked,.id

Element Size & Scrolling:

    box.offsetHeight// full height (with border)
    box.clientHeight// visible height
    box.scrollHeight// total content height

        client → visible area
        scroll → full content
        offset → full box
    box.scrollTop = 50;// scroll inside box
    console.log(box.scrollTop);// current scroll position
