Event Bubbling

            document.body.innerHTML = `
            <div id="grandparent" style="padding:40px; background:lightblue">
                Grandparent
                <div id="parent" style="padding:40px; background:lightgreen">
                Parent
                <button id="child">Click Me</button>
                </div>
            </div>
            `;
            document.getElementById("grandparent").addEventListener("click", () => {
            console.log("Grandparent capturing");
            });

            document.getElementById("parent").addEventListener("click", () => {
            console.log("Parent capturing");
            });

            document.getElementById("child").addEventListener("click", () => {
            console.log("Child capturing");
            });
            Child runs
            Then parent runs
            Then grandparent runs

            This is BUBBLING


Event capturing

            document.getElementById("grandparent").addEventListener("click", () => {
            console.log("Grandparent capturing");
            }, true);

            document.getElementById("parent").addEventListener("click", () => {
            console.log("Parent capturing");
            }, true);

            document.getElementById("child").addEventListener("click", () => {
            console.log("Child capturing");
            }, true);
            Grandparent
            Parent
            Child

            This is CAPTURING
            “Event comes from top → down to target”


Browser Default Actions

    Every HTML element has built-in behavior
        like  <a> → navigates to a link
             <form> → reloads page on submit
             <input> → typing text
    Sometimes you don’t want the default behavior -->preventDefault()
