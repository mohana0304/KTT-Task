Object relational mapping - 
        is a programming technique let us to interact with
        a relational database using objects instead of writing raw sql queries

        table in database - becomes js objects(models /classes)
        rows - becomes instance of those objects
        columns - mapped to object properties

        sql queries - become js method callbacks

setting sequelize:
        npm install sequelize pg pg-hstore - install sequelize for postgreSQL
        
        switching between database :
                dialect: 'mysql'

associations :
              define relationships between models
              
              1.one to one 
                        each record in table A is linked to one record in table Backend
                        one user -> one profile //user is parent ,profiile stores the foreign key
                        user.hasOne(profile);
                        profile.belongsTo(user);

              2.one to many 
                        table A can have multiple records in table Backend
                        one user -> many posts //foreign key goes into post table
                        user.hasMany(post);
                        post.belongsTo(user);// post will have userId

              3.many to many
                        multiple records in table a relate to multiple in table B 
                        students <-> courses
                        Student.belongsToMany(Course, { through: 'Enrollment' });
                        Course.belongsToMany(Student, { through: 'Enrollment' });

postgreSQL support storing JSON data inside columns, 
which is useful for flexible or semi-structured data

{
  "name": "John",
  "age": 25,
  "skills": ["JS", "SQL"]
}
 
 accessing JSON data:
                     ->  - return JSON object
                     ->> - return value as TEXT
                     SELECT params->'name' FROM events;//"John" (JSON format)
                     SELECT params->>'name' FROM events;// John (plain text)
 
 filtering Data:
                use JSON values inside where
                SELECT * FROM events WHERE params->>'name' = 'Click Button';
                //{ "name": "Click Button" }
                PostgreSQL allows filtering directly on JSON keys
 
 Accessing JSON arrays:
                       {  "ids": [10, 20, 30] }
                       SELECT params->'ids'->0 FROM events;//10

 working with nested JSON:
                          { 
                          "preferences": 
                          {"beta": true  }
                          }
                          select * from users where (preferences->>'beta')::boolean IS TRUE;
                          ->> get value as text
                          ::boolean onverts to boolean

json - stores raw text
jsonb - store binary (optimized)
        faster queries
        support indexing
        more operators

->      - get JSON value
->>     - get text value
#>      - get nested object
#>>     - get nested text
@>      -check if JSON contains value
